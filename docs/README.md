## A note on drift

This directory was twenty-nine documents, then sixteen, and is now eleven. Everything
removed is in git history. The pattern each time was the same: a document written from a
survey rather than from the code describes a state of the world that has passed.

Two rules keep it small. Prefer asserting a claim in a test over restating it in prose.
And never copy a value that lives in code — a migration head, a capability count, a fee in
basis points — into a sentence here, because it will drift and nothing will catch it.
