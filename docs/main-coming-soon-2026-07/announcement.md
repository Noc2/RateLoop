## Coordination checklist

1. Prepare the final post and image before the production change.
2. Deploy and complete the verification checklist in `integration-plan.md`.
3. Check the X card against the final public URL; change the image URL if a stale cache persists.
4. Publish the single post. Use the thread only if more context is actually needed.
5. If the site rolls back after publication, unpin the announcement and add a correction rather than leaving a broken
   promise visible.

Do not announce a date, waitlist, or new product scope until it is real. The launch message should express status and
gratitude, not create an unsupported commitment.
